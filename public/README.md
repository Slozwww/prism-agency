## 📦 Installation

### Option 1 : Fichiers Séparés (Recommandé)

1. Téléchargez tous les fichiers
2. Placez-les dans un même dossier
3. Ouvrez `index.html` dans votre navigateur

### Option 2 : Fichier Unique

1. Téléchargez `prism-agency-complete.html`
2. Ouvrez-le dans votre navigateur
3. Tout fonctionne en un seul fichier !

## 🌍 Hébergement Gratuit

### Netlify (Recommandé)
1. Créez un compte sur [netlify.com](https://netlify.com)
2. Glissez-déposez votre dossier
3. Votre site est en ligne ! ⚡

### GitHub Pages
1. Créez un repository sur [github.com](https://github.com)
2. Uploadez vos fichiers
3. Activez GitHub Pages dans les paramètres

### Vercel
1. Créez un compte sur [vercel.com](https://vercel.com)
2. Importez votre projet
3. Déployez en un clic
